# EMPsize for Safari (iPhone, iPad and Mac)

`safari/extension/` is the same code as the Chrome build, with a Safari-friendly manifest (non-persistent background, Safari 16.4+). It is generated by `../build.sh` from `../src/`.

## On your Mac (one time)
1. Install Xcode from the Mac App Store and open it once. Sign in at Xcode > Settings > Accounts with your Apple Developer account.
2. Copy this whole `safari/` folder to the Mac. You can also use `empsize-safari-extension.zip`: unzip it into a folder named `extension`.
3. In Terminal:
   ```
   cd path/to/safari
   xcrun safari-web-extension-converter extension \
     --project-location ./xcode --app-name "EMPsize" \
     --bundle-identifier com.yourname.focusreader --swift --copy-resources
   ```
   This makes an Xcode project with iOS and macOS apps. Add `--ios-only` or `--macos-only` if you only want one.
4. Xcode opens. For **each** target (iOS app, iOS extension, macOS app, macOS extension), go to *Signing & Capabilities*, turn on "Automatically manage signing", and pick your Team.

## Run on your Mac
1. Choose the "EMPsize (macOS)" scheme and press Run (⌘R). The app opens; you can close it.
2. Open Safari > Settings > Extensions and tick **EMPsize**. (While developing, you may first need Safari > Settings > Advanced > "Show features for web developers", then Develop > "Allow unsigned extensions". This isn't needed once the app is signed and archived.)
3. Click the EMPsize toolbar button and pick "Always allow on every website" (or allow just the current site).

## Run on your iPhone
1. Plug in the iPhone (or pair it over Wi-Fi). On the phone, turn on Settings > Privacy & Security > Developer Mode and restart if asked.
2. In Xcode, choose the "EMPsize (iOS)" scheme and your iPhone as the destination, then press Run.
3. On the iPhone, go to **Settings > Apps > Safari > Extensions > EMPsize**. Turn it on and set "All Websites" to **Allow**. Also turn on "Private Browsing" if you want it there.
4. In Safari, tap the **Aa** / puzzle-piece icon in the address bar, then tap **EMPsize** and hit the big switch.

## TestFlight / App Store
In Xcode, choose Product > Archive, then Distribute App > App Store Connect > Upload. Add the build to TestFlight in App Store Connect. Archive the iOS and macOS apps separately, each with its own scheme.

## Where it works / doesn't (brief)
- **Works:** normal and Private Safari tabs, once you allow it per site or for all sites. Private tabs need an extra toggle. This includes linkedin.com in Safari and links you open in Safari.
- **Doesn't:** in-app browsers (LinkedIn, Gmail and X apps all use Safari View Controller or their own web views, which don't run extensions; use "Open in Safari"). Also not in Safari Reader view, PDFs, or iframes (main page only).
- **No Alt+B on iPhone:** Safari on iOS doesn't support keyboard shortcuts for extensions; use the popup. On the Mac, the shortcut may work or can be set in Safari.
- **Settings stay on each device:** `storage.sync` doesn't sync in Safari, so the iPhone and Mac keep separate settings.
