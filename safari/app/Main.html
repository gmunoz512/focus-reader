empsize

bolds the start of every word so your eyes glide through text.

you only need to open this app once.

checking…

set up on iphone / ipad

  1. 1

    open settings

    settings › apps › safari › extensions › empsize

  2. 2

    turn it on

    flip the switch, then set all websites to allow.

  3. 3

    use it in safari

    tap the aa / puzzle menu, then empsize, then the big switch.

set up on mac

  1. 1

    open safari settings

    safari › settings › extensions

  2. 2

    turn it on

    check empsize, then allow it on all websites.

  3. 3

    use it

    click the empsize icon in the toolbar and flip the big switch. alt+b also works.

good to know

  1. ·

    leaves code, inputs and links alone. no tracking, no network.

  2. ·

    works in safari, not inside other apps' built-in browsers. use "open in safari" there.
